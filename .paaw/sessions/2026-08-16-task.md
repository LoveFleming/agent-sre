**`server/routes.mjs`** — 新增 4 個 endpoints，資料層直接用 TASK-002 依賴的 `agent-store.mjs`：

| Endpoint | 行為 |
|---|---|
| `GET /api/agents` | 列表（`{ agents: [...] }`，createdAt 升冪） |
| `POST /api/agents` | 建立 → 201；id 由 `saveAgent` 產生 UUID，client 傳的 id 會被 store 忽略 |
| `GET /api/agents/:id` | 單筆 → 200；不存在 → 404 |
| `PUT /api/agents/:id` | partial patch（未傳欄位保留舊值）→ 200 |
| `DELETE /api/agents/:id` | `{ success: true, id }` → 200 |

錯誤處理：400（缺 `name`、缺 `prompt`、body 非物件、schema 違規、invalid/traversal id）→ 404（`Agent not found`）→ error body 沿用 `{ "error": ... }` 慣例。
